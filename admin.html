Настройка входа

Делает помощник: в первый раз, когда нужен новый пароль и когда ключ истёк. Сайт хранит данные в своём репозитории на GitHub, поэтому админке нужен ключ GitHub с правом записи только в этот репозиторий. Ключ шифруется логином и паролем — админ входит только по ним.

  1. Откройте ключи на GitHub (Fine-grained tokens). Ключ уже есть — откройте его и нажмите Regenerate token: старый ключ и все старые пароли перестанут работать. Ключа нет — Generate new token. Если сделали новый ключ, а старый был, — удалите старый.
  2. Resource owner — владелец сайта. Expiration — самый долгий срок. Repository access — Only select repositories → только этот репозиторий.
  3. Permissions → Repository permissions → Contents: Read and write. Generate token.
  4. Вставьте ключ ниже, задайте логин, нажмите «Придумать пароль» и передайте логин и пароль админу.

Не короче 10 символов, не только цифры, без логина внутри. Надёжнее — «Придумать пароль».

Вход по новому паролю заработает примерно через минуту.
